## Install

1. [Download Sukusho](https://github.com/tommyent/sukusho/releases/latest) and open the DMG.
2. Drag Sukusho to Applications and open it.
3. Allow Screen & System Audio Recording when macOS asks.

Sharing uses a Worker in your own Cloudflare account: [set it up](docs/sharing-setup.md).

Tested on macOS 27.0.1 and 27.3 on Apple silicon. Signed and notarized; updates are available in the app.
